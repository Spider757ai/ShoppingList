# ShoppingList

Приложение для списка покупок на Swift и SwiftUI.

**Автор:** Артур  
**Группа:** БПИ 263

## Возможности

- Добавление покупки: название, категория и количество.
- Отметка купленных товаров.
- Редактирование покупки на отдельном экране.
- Поиск по названию и категории без учёта регистра.
- Удаление свайпом, в том числе во время поиска.
- Сообщение, если список пуст или ничего не найдено.

Пустое название сохранить нельзя. Количество можно выбрать от 1 до 99.

## Дополнительно

- Фильтр: все покупки, нужно купить или уже куплено.
- Сортировка по названию, категории и количеству.
- Счётчик оставшихся покупок.
- Сохранение списка между запусками.
- Выбор категории из списка и цветные значки.
- Удаление лишних пробелов в названии.

## Как устроено

Для каждой покупки хранятся название, категория, количество и статус. Главный экран показывает список, форма нужна для добавления, а экран подробностей — для редактирования.

## Запуск

Открыть проект в Xcode, выбрать симулятор iPhone и нажать `⌘R`.
