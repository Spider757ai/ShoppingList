# ShoppingList — список покупок

Учебный проект на Swift и SwiftUI по [заданию «Список покупок»](https://github.com/ProSkyMishka/NIS/blob/main/Домашнее-задание-лонгрид.md).

**Автор:** Артур.  
**Группа:** БПИ 263.

## Текущее состояние

В репозиторий добавлены модель покупки `ShoppingItem` и точка входа SwiftUI-приложения `MyApp`. Это начальный этап работы: экран `ContentView` и Xcode-проект пока не добавлены, поэтому опубликованных файлов недостаточно для сборки и запуска приложения.

## Что реализовано

- Модель `ShoppingItem` с уникальным идентификатором `UUID`.
- Поля для названия, категории, количества и статуса покупки.
- Поддержка протоколов `Identifiable` и `Hashable`.
- Инициализатор со значениями по умолчанию: новый `UUID`, количество `1`, статус «не куплено».
- Три примера покупок в `ShoppingItem.samples`.
- Точка входа `@main`: `MyApp` создаёт `WindowGroup` с `ContentView`.

### Примеры данных

| Название | Категория | Количество | Статус |
| --- | --- | ---: | --- |
| Молоко | Продукты | 2 | Нужно купить |
| Блокнот | Учёба | 1 | Нужно купить |
| Батарейки | Дом | 1 | Куплено |

## Подготовка к запуску

Для сборки iOS-приложения нужен Mac с Xcode и установленным iOS Simulator.

1. Склонировать репозиторий:

   ```bash
   git clone https://github.com/Spider757ai/ShoppingList.git
   cd ShoppingList
   ```

2. Добавить в репозиторий свой Xcode-проект. Если проекта ещё нет, создать в Xcode проект типа **iOS App** с интерфейсом **SwiftUI** и языком **Swift**.
3. Добавить `ShoppingItem.swift` в целевой модуль приложения. Код `MyApp` из `main.swift` использовать вместо автоматически созданной точки входа: в модуле должна остаться только одна структура с `@main`.
4. Добавить `ContentView.swift` и остальные представления из своего проекта.
5. Выбрать симулятор iPhone, собрать проект через `⌘B` и запустить через `⌘R`.

Пока отсутствует `ContentView`, этот порядок подготовки не позволяет запустить приложение без добавления недостающего кода.
