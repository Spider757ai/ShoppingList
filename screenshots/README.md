# Скриншоты

Снимки экрана приложения можно загрузить сюда через **Add file → Upload files**.

| Файл | Экран |
| --- | --- |
| `main.png` | Список покупок, отметка купленного и счётчик |
| `add.png` | Форма добавления с заполненным названием |
| `detail.png` | Редактирование покупки |
| `filter.png` | Список с выбранным фильтром «Куплено» |
| `sort.png` | Открытое меню сортировки |
| `categories.png` | Выбор категории |
